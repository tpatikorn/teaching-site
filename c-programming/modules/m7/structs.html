7.1 Struct Alignment & Padding

Understand how compilers arrange variables in structured memory, insert padding, and calculate sizes.

Memory Padding and Sizeof

To optimize CPU memory reads, data types are aligned to address boundaries that match their sizes (e.g., 4-byte integers start at address multiples of 4). Compilers insert blank padding bytes to enforce this. The arrangement of members directly affects the struct size.

1. Struct Padding Rules

• Compilers align variables to multiples of their natural size.
• Suboptimal layouts (e.g. char followed by int) force the compiler to insert 3 padding bytes before the int so it starts on a multiple of 4.
• Ordering members from largest size to smallest size yields the most compact structure.

2. Unions

• Declared similarly to structs but all members share the same starting address in memory.
• Size of a union is equal to the size of its largest member. Only one member value can be stored at any given time.

3. File streams (FILE * )

C handles files via standard stream buffers:
• fopen("filename", "mode"): Modes include "r" (read), "w" (write, overwrites), "a" (append, writes to end). Add "b" for binary operations (e.g. "rb").
• Standard pre-opened streams: stdin, stdout, and stderr.
