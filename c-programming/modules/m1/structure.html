1. Preprocessor Directives (#include & #define)

Lines beginning with # are processed by the preprocessor before actual code compilation begins:

  • #include <stdio.h>: Inserts system header files containing standard I/O library function prototypes (e.g., printf, scanf).
  • #include "myheader.h": Inserts user-defined local header files located in the current project directory.
  • #define MAX 100: Textual macro substitution that replaces every occurrence of MAX with 100 before compiling.
  • Header Guards: Uses #ifndef HEADER_H, #define HEADER_H, and #endif to prevent duplicate declaration errors during inclusion.

2. Entry Point & Function Anatomy

Every executable C program requires exactly one primary entry point function:

  • int main(): The entry point function called by the C runtime startup code (crt0.o).
  • Command-Line Arguments: int main(int argc, char *argv[]) receives argument count (argc) and an array of null-terminated strings (argv).
  • Return Exit Status: Returning 0 (or EXIT_SUCCESS) signals successful execution to the OS. Returning a non-zero value (e.g., 1 or EXIT_FAILURE) indicates runtime errors.

3. Standard Stream Buffers

C programs interact with operating system environments via three pre-opened file streams:

  • stdin (File Descriptor 0): Standard input stream, line-buffered by default (keyboard input).
  • stdout (File Descriptor 1): Standard output stream, flushed automatically on newline (\n) or program termination.
  • stderr (File Descriptor 2): Standard error stream, unbuffered by default so diagnostic messages print immediately during crashes.
