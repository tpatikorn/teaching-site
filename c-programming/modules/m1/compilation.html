Multi-Stage Build Pipeline Mechanics

Unlike interpreted languages (like Python or JS), C source code must go through 4 distinct stages to produce a standalone runnable executable binary:

  • 1. Preprocessing: Macro substitution, header inclusions, comment stripping (Output: .i file).
  • 2. Compilation: Translates C constructs into architecture-specific assembly instructions (Output: .s file).
  • 3. Assembly: Converts assembly instructions into raw binary CPU machine opcodes (Output: .o / .obj file).
  • 4. Linking: Resolves function call addresses and combines object files with standard libraries (Output: .exe / a.out).
