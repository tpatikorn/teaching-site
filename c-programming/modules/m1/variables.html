1.2 Variables & Data Types

Understand data type sizes, standard format specifiers, scope lifetimes, and visualize how variables map to stack memory bytes in Little-Endian layout.

1. Fundamental Data Types & Byte Sizes

Declaring a variable reserves a specific number of contiguous bytes in RAM memory:

  • char (1 byte): Stores a single ASCII character or small integer (-128 to 127 signed, 0 to 255 unsigned).
  • short (2 bytes): Small integer representation (-32,768 to 32,767).
  • int (4 bytes): Standard integer value (-2,147,483,648 to 2,147,483,647).
  • long long (8 bytes): 64-bit wide integer for large range data.
  • float (4 bytes): IEEE 754 single-precision floating point (approx. 7 decimal digits of precision).
  • double (8 bytes): IEEE 754 double-precision floating point (approx. 15 decimal digits of precision).

2. Format Specifiers & I/O Modifiers

Format specifiers instruct printf and scanf how to interpret binary memory patterns:

  • %d / %i: Signed decimal integer.
  • %u: Unsigned decimal integer.
  • %x / %X: Hexadecimal integer output (lowercase / uppercase).
  • %f / %lf: Floating point decimal format (%lf for double in scanf).
  • %c: Character representation of ASCII integer code.
  • %p: Pointer memory address in hexadecimal format.
  • Formatting Flags: %.2f (rounds float to 2 decimal places), %05d (pads integer with leading zeroes up to width 5).

3. Scopes, Lifetimes & Storage Classes

Variable scope determines where a variable can be accessed and how long it stays in memory:

  • Local Automatic (Stack): Declared inside function blocks. Allocated when the function runs; contains garbage values if not initialized!
  • Global Variables (.data / .bss): Declared outside functions. Available throughout the entire execution lifetime, zero-initialized by default.
  • static Keyword: Preserves a local variable's stored value across multiple function invocation calls.
  • const Qualifier: Makes a variable read-only; attempting to modify it causes a compilation error.

4. Memory Endianness (Little-Endian vs Big-Endian)

Endianness defines the order in which bytes of multi-byte numbers (e.g. 4-byte int) are arranged in memory:

  • Little-Endian (x86 / x64 / ARM): The Least Significant Byte (LSB) is stored at the lowest memory address. For example, integer 258 (hex 0x00000102) is stored as byte sequence [02] [01] [00] [00].
  • Big-Endian (Network Byte Order): The Most Significant Byte (MSB) is stored at the lowest memory address (e.g., [00] [00] [01] [02]).
