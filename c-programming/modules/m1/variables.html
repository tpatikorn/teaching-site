1. Standard Sizes & Ranges

C defines standard ranges for data types:
• char: 1 byte (signed: -128 to 127, unsigned: 0 to 255)
• int: 4 bytes (typically)
• float: 4 bytes (single-precision floating point)
• double: 8 bytes (double-precision floating point)

2. Format Specifiers

Used in printf and scanf to identify type categories:
• %d or %i: decimal integer
• %f: float (printed as decimal)
• %lf: double (in scanf, printf can also use %f)
• %c: single character
• %s: character string array

3. Local Scopes & Garbage Values

Variables declared inside a function are local. They are not automatically initialized by C and start with garbage values (random bytes left over in RAM).
Use the static keyword to preserve a local variable's state across multiple function calls.
