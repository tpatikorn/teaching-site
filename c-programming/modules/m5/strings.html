5.1 Strings & Null Termination (\0)

Understand how C represents text as character arrays terminated by a special zero byte.

Null-Terminated Arrays

Unlike other languages, C strings don't store their length explicitly. Functions scan until they hit the null character '\\0' (ASCII 0). Type a string and simulate library actions below.

1. Contiguous Layout & 2D Arrays

Arrays allocate contiguous memory.
• Row-Major Order: In a 2D array, rows are stored sequentially in memory (e.g. Row 0 elements, then Row 1 elements). The address offset formula is: &A[i][j] = Base + i * C + j (where C is total columns).

2. Null Terminator '\0'

A C string is simply an array of characters ending with '\0'.
• ASCII value is 0.
• Marks the boundary. Without '\0', functions will read out-of-bounds until they hit a random 0 byte, causing garbage outputs or segfaults.

3. String Library Helper Functions

• strlen(s): Returns length of string (does not count '\0').
• strcpy(dest, src): Copies source to destination buffer (must have enough size).
• strcmp(s1, s2): Compares strings alphabetically (returns 0 if equal).
