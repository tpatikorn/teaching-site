1. For Loops 1. โครงสร้างลูป For

• Preferred when the number of iterations is known beforehand.
• Execution steps: initialization, condition check, body execution, variable update, check again. • นิยมใช้เมื่อทราบจำนวนรอบการทำซ้ำล่วงหน้าแน่นอน
• ขั้นตอนการทำงาน: กำหนดค่าเริ่มต้น, ตรวจสอบเงื่อนไข, ทำงานคำสั่งในลูป, ปรับค่าตัวแปรควบคุม, ตรวจสอบใหม่

2. While Loops 2. โครงสร้างลูป While

• Evaluates the condition before entering the loop body.
• If the condition is false initially, the body does not execute at all (0 or more iterations). • ตรวจสอบเงื่อนไข ก่อน เข้าไปทำคำสั่งในบล็อกลูป
• หากเงื่อนไขเป็นเท็จตั้งแต่แรก บล็อกลูปจะไม่ทำเลยแม้แต่รอบเดียว (วนซ้ำตั้งแต่ 0 รอบขึ้นไป)

3. Do-While Loops 3. โครงสร้างลูป Do-While

• Evaluates the condition after executing the loop body.
• This guarantees that the loop body is executed at least once. • ตรวจสอบเงื่อนไข หลัง ทำงานคำสั่งในบล็อกลูปเสร็จในแต่ละรอบ
• สิ่งนี้รับประกันว่าบล็อกลูปจะทำงานอย่างน้อย หนึ่งรอบเสมอ
