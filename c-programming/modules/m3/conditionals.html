Conditionals & Switch-Case การตัดสินใจเชิงเงื่อนไขและ Switch-Case

Branching statements allow your program to run different code paths based on whether statements are true or match case tags. คำสั่งทางเลือกเงื่อนไขช่วยให้โปรแกรมเลือกทำเส้นทางรหัสที่แตกต่างกันตามการเป็นจริงของนิพจน์เงื่อนไขหรือการจับคู่ของป้ายกรณี

1. If-Else Statements 1. โครงสร้างเงื่อนไข If-Else

C checks conditions sequentially:
• The compiler evaluates the if condition first.
• If it evaluates to non-zero (true), the block is executed and others are skipped.
• If zero (false), it moves down to else if and finally fallback else. ภาษา C ตรวจสอบเงื่อนไขตามลำดับ:
• คอมไพเลอร์จะตรวจสอบเงื่อนไข if ก่อน
• หากเงื่อนไขเป็นจริง (ไม่ใช่ศูนย์) จะทำงานในบล็อกนั้นแล้วข้ามส่วนที่เหลือ
• หากเป็นเท็จ (ศูนย์) จะข้ามไปยัง else if หรือ else ตามลำดับ

2. Switch-Case Constraints 2. เงื่อนไขและข้อจำกัดของ Switch-Case

Switch statements compare a single expression against constant values:
• Strict Type Rule: The expression inside switch(expr) must evaluate to an integer or character type (like int, char). Floating-point values (float, double) or string pointers are strictly illegal. คำสั่ง Switch เปรียบเทียบผลลัพธ์ของนิพจน์เดียวกับค่าคงที่:
• กฎชนิดข้อมูลเข้มงวด: นิพจน์ภายใน switch(expr) ต้องได้ผลลัพธ์เป็น จำนวนเต็ม หรือ ตัวอักษร (เช่น int, char) การใช้ค่าทศนิยมหรือข้อความถือว่าผิดกฎหลักไวยากรณ์โดยตรง

3. Fall-through & Break 3. การไหลต่อเนื่อง (Fall-through) และ Break

• Cases in a switch do not automatically terminate.
• Without a break statement, execution continues (falls through) to the next case tag regardless of whether the tag matches. • บล็อก Case ใน Switch จะไม่สิ้นสุดการทำงานโดยอัตโนมัติ
• หากไม่มีคำสั่ง break การประมวลผลจะไหลต่อเนื่องไปยัง Case ลำดับถัดไปโดยไม่ตรวจสอบการจับคู่เงื่อนไข
