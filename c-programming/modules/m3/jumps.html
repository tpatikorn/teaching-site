3.3 Jump Statements (break/continue & return) 3.3 คำสั่งข้ามการทำงานและคำสั่งย้อนกลับ (break/continue & return)

Trace jump statement redirections, loop breaks, continue updates, and function return flows step-by-step. ตัวติดตามและจำลองโครงสร้างคำสั่ง break, continue และการทำงานร่วมกับ return ทีละขั้นตอน

Jump Statements Trace การติดตามคำสั่งข้ามการทำงาน

Jump statements alter the execution flow by unconditionally transferring control to another line of code. คำสั่งข้ามการทำงานจะแก้ไขลำดับประมวลผลโดยการโอนย้ายควบคุมไปยังส่วนอื่นโดยไม่มีเงื่อนไข

1. Break Statement 1. คำสั่ง Break

• Immediately terminates the execution of the innermost for, while, do-while, or switch statement.
• Execution continues at the next line immediately following the loop/switch block. • ยุติลูปในสุด (for, while, do-while) หรือ switch ที่ทำงานครอบอยู่ทันที
• การประมวลผลจะทำงานต่อที่บรรทัดถัดไปทันทีหลังจบบล็อกลูป/switch นั้น

2. Continue Statement 2. คำสั่ง Continue

• Skips the rest of the statements in the current iteration of the innermost loop.
• Jumps directly to the condition test (for while) or update expression (for for). • ข้ามขั้นตอนคำสั่งที่เหลือทั้งหมดในรอบการทำงานปัจจุบันของลูปชั้นในสุด
• กระโดดข้ามไปยังเงื่อนไขตรวจสอบ (สำหรับ while) หรือการปรับปรุงค่านิพจน์ควบคุม (สำหรับ for) ทันที

3. Return Statement interaction 3. ผลของคำสั่ง Return ร่วมกับลูป

• Immediately terminates execution of the entire containing function.
• If executed inside a loop, it breaks out of the loop and exits the function instantly, skipping any trailing logic in or outside the loop. • ปิดการประมวลผลและยุติการเรียกทำงานทั้งหมดของฟังก์ชันนั้นทันที
• หากประมวลผลภายในลูป จะออกจากลูปและฟังก์ชันในเสี้ยววินาที ข้ามคำสั่งถัดไปทั้งหมดไม่ว่าจะอยู่ในหรือนอกลูป
