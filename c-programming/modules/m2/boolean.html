2.2 Boolean & Relational Operations 2.2 ตัวดำเนินการเปรียบเทียบและตรรกศาสตร์

Master relational comparisons (==, !=, <, >), logical boolean operators (&&, ||, !), short-circuit evaluation rules, and ternary conditional expressions. เรียนรู้ตัวดำเนินการเปรียบเทียบ ค่าความจริง ตรรกศาสตร์ (&&, ||, !) กฎการประเมินค่าแบบลัดวงจร (Short-Circuit) และ Ternary Operator

1. Relational Operators & Truth Representation in C 1. ตัวดำเนินการเปรียบเทียบและการแทนค่าความจริงใน C

In C (C99 and prior), there is no native primitive boolean keyword by default; boolean values are represented numerically: ในภาษา C ค่าความจริง (Boolean) ถูกแทนด้วยตัวเลขจำนวนเต็มเป็นหลัก:

  • False: Represented by exact integer 0. เท็จ (False): แทนด้วยค่าจำนวนเต็ม 0
  • True: Evaluates to integer 1 for relational comparisons; any non-zero value (e.g. -5, 42) is treated as True in conditionals! จริง (True): การเปรียบเทียบจะคืนค่า 1; ค่าที่ไม่ใช่ศูนย์ทั้งหมด (เช่น -5, 42) ถือว่าเป็น จริง ในการตรวจสอบเงื่อนไข!
  • Relational Set: Equal ==, Not Equal !=, Greater >, Less <, Greater or Equal >=, Less or Equal <=. ตัวดำเนินการเปรียบเทียบ: เท่ากับ ==, ไม่เท่ากับ !=, มากกว่า >, น้อยกว่า <, มากกว่าหรือเท่ากับ >=, น้อยกว่าหรือเท่ากับ <=

2. Logical Operators (&&, ||, !) 2. ตัวดำเนินการทางตรรกศาสตร์ (AND, OR, NOT)

Combine multiple boolean conditions into complex logical expressions: รวมเงื่อนไขย่อยหลายเงื่อนไขเข้าด้วยกันเป็นนิพจน์ตรรกศาสตร์:

  • Logical AND (&&): Evaluates to 1 if and only if both operands are non-zero (true). Logical AND (&&): เป็นจริง (1) ก็ต่อเมื่อเงื่อนไขทั้งสองฝั่งเป็นจริงทั้งคู่
  • Logical OR (||): Evaluates to 1 if at least one operand is non-zero (true). Logical OR (||): เป็นจริง (1) เมื่อมีเงื่อนไขอย่างน้อยหนึ่งฝั่งเป็นจริง
  • Logical NOT (!): Inverts truth state: !0 becomes 1, while !1 (or !non-zero) becomes 0. Logical NOT (!): นิเสธหรือกลับค่าความจริง: !0 กลายเป็น 1 และ !1 (หรือ !ค่าไม่ใช่ศูนย์) กลายเป็น 0

3. Short-Circuit Evaluation Rules 3. กฎการประเมินผลแบบลัดวงจร (Short-Circuit Evaluation)

C optimizes logical expressions by evaluating left-to-right and stopping as soon as the final result is guaranteed: ภาษา C เพิ่มประสิทธิภาพการประเมินผลโดยหยุดประเมินฝั่งขวาทันทีเมื่อทราบผลลัพธ์สุดท้ายแน่ชัด:

  • AND Short-Circuit (A && B): If A evaluates to 0 (false), B is NEVER executed or evaluated! (e.g. ptr != NULL && ptr->val > 0 safely avoids null dereference crashes). AND Short-Circuit (A && B): ถ้า A เป็น 0 (เท็จ) ฝั่ง B จะ ไม่ถูกประเมินผลหรือทำงานเลย! (ช่วยป้องกันการเข้าถึงพอยเตอร์ที่เป็น NULL)
  • OR Short-Circuit (A || B): If A evaluates to non-zero (true), B is skipped completely because the entire expression is already true. OR Short-Circuit (A || B): ถ้า A เป็นจริง (ไม่ใช่ 0) ฝั่ง B จะ ถูกข้ามไปทันที เพราะทั้งนิพจน์เป็นจริงแน่นอนแล้ว

4. Ternary Conditional Operator (? :) 4. ตัวดำเนินการเงื่อนไขสามระดับ (Ternary Operator)

Provides a concise inline if-else expression: condition ? expr_if_true : expr_if_false. (e.g., int max = (a > b) ? a : b;). คำสั่งตัดสินใจแบบย่อในบรรทัดเดียว: เงื่อนไข ? นิพจน์ถ้าเป็นจริง : นิพจน์ถ้าเป็นเท็จ (เช่น int max = (a > b) ? a : b;)
