2.3 Bitwise Operations 2.3 ตัวดำเนินการระดับบิต (Bitwise Operations)

Manipulate raw binary bits directly with AND (&), OR (|), XOR (^), NOT (~), Left Shift (<<), Right Shift (>>), and bit masking flags. จัดการและคำนวณบิตในระดับฮาร์ดแวร์โดยตรงด้วยตัวดำเนินการ AND (&), OR (|), XOR (^), NOT (~), เลื่อนบิตซ้าย (<<) และขวา (>>)

1. Bitwise Logical Operators (&, |, ^, ~) 1. ตัวดำเนินการตรรกศาสตร์ระดับบิต (&, |, ^, ~)

Operates on individual bit positions of integer operands in binary form: ประมวลผลบิตแต่ละตำแหน่งของตัวเลขจำนวนเต็มในรูปแบบเลขฐานสอง:

  • Bitwise AND (&): Output bit is 1 if and only if both corresponding input bits are 1. Used for Bit Masking & Testing. Bitwise AND (&): บิตลัพธ์เป็น 1 เมื่อบิตของทั้งสองฝั่งเป็น 1 ทั้งคู่ นิยมใช้สำหรับ ตรวจสอบบิต (Bit Masking)
  • Bitwise OR (|): Output bit is 1 if at least one corresponding input bit is 1. Used for Setting Bits / Enabling Flags. Bitwise OR (|): บิตลัพธ์เป็น 1 เมื่อบิตฝั่งใดฝั่งหนึ่งเป็น 1 นิยมใช้สำหรับ เปิดสวิตช์หรือกำหนดค่าบิต (Setting Flags)
  • Bitwise XOR (^): Output bit is 1 if input bits are different. Used for Toggling Bits & Fast Swaps. Bitwise XOR (^): บิตลัพธ์เป็น 1 เมื่อบิตทั้งสองฝั่ง ต่างกัน นิยมใช้สำหรับ สลับสถานะบิต (Toggle) หรือสลับค่าตัวแปร
  • Bitwise NOT (~): Unary bitwise complement that flips every 0 to 1 and every 1 to 0 (Two's complement negation). Bitwise NOT (~): กลับค่าบิตทั้งหมดจาก 0 เป็น 1 และจาก 1 เป็น 0 (การหาผลเติมเต็ม 1's Complement)

2. Bit Shift Operators (<<, >>) 2. ตัวดำเนินการเลื่อนบิต (Shift Operators <<, >>)

Shifts binary bit sequences left or right by a specified number of positions: เลื่อนตำแหน่งบิตฐานสองไปทางซ้ายหรือทางขวาตามจำนวนหลักที่กำหนด:

  • Left Shift (<< N): Shifts bits left by N places, filling empty LSB slots with zeroes. Equivalent to multiplying integer by $2^N$ (e.g. 5 << 2 is $5 \times 4 = 20$). เลื่อนบิตไปทางซ้าย (<< N): เลื่อนบิตไปทางซ้าย N ตำแหน่ง เติม 0 ในช่องว่างฝั่งขวา มีค่าเท่ากับ คูณด้วย $2^N$ (เช่น 5 << 2 คือ $5 \times 4 = 20$)
  • Right Shift (>> N): Shifts bits right by N places. Equivalent to integer division by $2^N$ (e.g. 20 >> 2 is $20 / 4 = 5$). เลื่อนบิตไปทางขวา (>> N): เลื่อนบิตไปทางขวา N ตำแหน่ง มีค่าเท่ากับ หารด้วย $2^N$ แบบตัดเศษ (เช่น 20 >> 2 คือ $20 / 4 = 5$)

3. Bit Masking Techniques 3. เทคนิคการใช้มาร์สก์บิต (Bit Masking)

Common bitwise patterns used in embedded programming and OS flags: รูปแบบการจัดการบิตมาตรฐานในระบบสมองกลฝังตัวและระบบปฏิบัติการ:

  • Set Bit N: flags |= (1 << N); เปิดบิตที่ N: flags |= (1 << N);
  • Clear Bit N: flags &= ~(1 << N); ปิดบิตที่ N: flags &= ~(1 << N);
  • Toggle Bit N: flags ^= (1 << N); สลับบิตที่ N: flags ^= (1 << N);
  • Test Bit N: if (flags & (1 << N)) { /* Bit is Set */ } ตรวจสอบบิตที่ N: if (flags & (1 << N)) { /* บิตเป็น 1 */ }
