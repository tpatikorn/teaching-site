2.1 Operator Precedence & Evaluation

Understand how the compiler parses nested expressions, operator ranks, and associative rules.

Operators Guide & Reference ข้อมูลคู่มือตัวดำเนินการภาษา C

Below is a detailed reference of the core C operators, descriptions, and evaluation results. ตารางสรุปตัวดำเนินการภาษา C คำอธิบายการทำงาน และผลลัพธ์การประเมินค่าจากการใช้งานจริง

Symbol Name ชื่อเรียก Description คำอธิบาย Example Result ตัวอย่างผลลัพธ์
+ Addition การบวก Adds two numeric values. บวกค่าตัวเลขสองจำนวนเข้าด้วยกัน 5 + 3
Result: 8
- Subtraction การลบ Subtracts the right operand from the left. หักลบค่าตัวเลขฝั่งขวาออกจากฝั่งซ้าย 5 - 3
Result: 2
* Multiplication การคูณ Multiplies two numeric values. คูณค่าตัวเลขสองจำนวนเข้าด้วยกัน 5 * 3
Result: 15
/ Division การหาร Divides left operand by right. Integer division drops decimals. หารตัวเลขตัวแรกด้วยตัวที่สอง (จำนวนเต็มจะตัดเศษทศนิยมทิ้ง) 5 / 2
Result: 2
% Modulo เศษการหาร (Modulo) Finds the remainder of integer division. หาเศษที่เหลือจากการหารของจำนวนเต็ม 5 % 2
Result: 1
++ (pre) Pre-increment เพิ่มค่าก่อนใช้งาน Increments the variable first, then evaluates in expression. เพิ่มค่าตัวแปรก่อน แล้วจึงนำไปประมวลผลคำนวณ y = ++i (i=5)
Result: i = 6, y = 6
++ (post) Post-increment เพิ่มค่าทีหลัง Evaluates current value in expression, then increments variable. ใช้ค่าปัจจุบันในนิพจน์ประมวลผลก่อน แล้วจึงเพิ่มค่าตัวแปรตามหลัง y = i++ (i=5)
Result: i = 6, y = 5
-- (pre) Pre-decrement ลดค่าก่อนใช้งาน Decrements the variable first, then evaluates. ลดค่าของตัวแปรก่อน แล้วจึงนำไปประมวลผลในนิพจน์ y = --i (i=5)
Result: i = 4, y = 4
-- (post) Post-decrement ลดค่าทีหลัง Evaluates current value, then decrements variable. ใช้ค่าปัจจุบันในนิพจน์ก่อน แล้วจึงลดค่าตัวแปรตามหลัง y = i-- (i=5)
Result: i = 4, y = 5
== Equality ความเท่ากัน Checks if values match. Returns 1 (true) or 0 (false). ตรวจสอบว่าค่าเท่ากันหรือไม่ ส่งกลับ 1 (จริง) หรือ 0 (เท็จ) 5 == 5
Result: 1
!= Inequality ความไม่เท่ากัน Checks if values do not match. ตรวจสอบว่าค่าไม่เท่ากันหรือไม่ 5 != 3
Result: 1
< Less Than น้อยกว่า Checks if left is smaller than right. ตรวจสอบว่าค่าทางซ้ายน้อยกว่าทางขวาหรือไม่ 3 < 5
Result: 1
> Greater Than มากกว่า Checks if left is larger than right. ตรวจสอบว่าค่าทางซ้ายมากกว่าทางขวาหรือไม่ 3 > 5
Result: 0
<= Less Than or Equal น้อยกว่าหรือเท่ากับ Checks if left is smaller or equal. ตรวจสอบว่าทางซ้ายน้อยกว่าหรือเท่ากับทางขวาหรือไม่ 5 <= 5
Result: 1
>= Greater Than or Equal มากกว่าหรือเท่ากับ Checks if left is larger or equal. ตรวจสอบว่าทางซ้ายมากกว่าหรือเท่ากับทางขวาหรือไม่ 5 >= 6
Result: 0
&& Logical AND ตรรกศาสตร์ AND Returns 1 if both operands are true (non-zero). Short-circuits. เป็นจริง (1) หากเงื่อนไขทั้งคู่เป็นจริง มีการลัดวงจรการทำงาน 5 && 0
Result: 0
|| Logical OR ตรรกศาสตร์ OR Returns 1 if at least one operand is true. Short-circuits. เป็นจริง (1) หากมีอย่างน้อยหนึ่งเงื่อนไขเป็นจริง มีการลัดวงจรการทำงาน 5 || 0
Result: 1
! Logical NOT ตรรกศาสตร์ NOT Negates logical state: turns 0 to 1, and non-zero to 0. กลับค่าทางตรรกศาสตร์: จริงเปลี่ยนเป็นเท็จ และเท็จเป็นจริง !5
Result: 0
& Bitwise AND บิต AND Performs logical AND on bit pairs. เปรียบเทียบ AND ทีละบิตของเลขสองจำนวน 5 & 3 (0101 & 0011)
Result: 1 (0001)
| Bitwise OR บิต OR Performs logical OR on bit pairs. เปรียบเทียบ OR ทีละบิตของเลขสองจำนวน 5 | 3 (0101 | 0011)
Result: 7 (0111)
^ Bitwise XOR บิต XOR Performs logical XOR on bit pairs. เปรียบเทียบ XOR (ต่างกันเป็น 1) ทีละบิต 5 ^ 3 (0101 ^ 0011)
Result: 6 (0110)
~ Bitwise NOT บิต NOT Inverts all bits of the operand. กลับค่าบิต 0 เป็น 1 และ 1 เป็น 0 ทั้งหมด ~0 (8-bit unsigned)
Result: 255
<< Left Shift เลื่อนบิตไปทางซ้าย Shifts bits left by N spots, inserting zeros. เลื่อนตำแหน่งบิตไปทางซ้าย N ครั้ง (เทียบเท่ากับการคูณด้วย 2^N) 1 << 3
Result: 8
>> Right Shift เลื่อนบิตไปทางขวา Shifts bits right by N spots. เลื่อนตำแหน่งบิตไปทางขวา N ครั้ง (เทียบเท่ากับการหารด้วย 2^N) 8 >> 2
Result: 2
(type) Explicit Cast แปลงชนิดข้อมูลระบุรูปแบบ Explicitly forces a value to convert to the target type. บังคับเปลี่ยนประเภทประเภทข้อมูลเป็นชนิดที่ระบุอย่างเจาะจง (float)5 / 2
Result: 2.5
