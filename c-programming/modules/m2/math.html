2.1 Arithmetic Operations 2.1 ตัวดำเนินการทางคณิตศาสตร์

Master binary and unary math operators (+, -, *, /, %), integer truncation vs floating-point division, pre/post increments (++x, x++), and explicit type casting. เรียนรู้ตัวดำเนินการทางคณิตศาสตร์พื้นฐาน การหารจำนวนเต็ม ทศนิยม การเพิ่ม/ลดค่า (++x, x++) และการแปลงชนิดตัวแปร (Type Casting)

1. Binary Arithmetic Operators 1. ตัวดำเนินการคณิตศาสตร์สองระดับ (Binary Operators)

C supports standard arithmetic operators that compute values between two operands: ภาษา C รองรับตัวดำเนินการคณิตศาสตร์มาตรฐานสำหรับคำนวณค่าระหว่างสองตัวแปร:

  • Addition (+) & Subtraction (-): Computes sum and difference between numbers. การบวก (+) และ การลบ (-): คำนวณผลรวมและผลต่างของตัวเลข
  • Multiplication (*): Multiplies two numeric factors. การคูณ (*): คำนวณผลคูณของสองจำนวน
  • Division (/): Integer division (e.g. 5 / 2) truncates the fractional part to 2! Floating-point division requires at least one float/double operand (e.g. 5.0 / 2 yields 2.5). การหาร (/): การหารจำนวนเต็ม (เช่น 5 / 2) จะตัดเศษทศนิยมทิ้งเหลือ 2! หากต้องการผลลัพธ์ทศนิยมต้องมีตัวแปร float/double อย่างน้อย 1 ตัว (เช่น 5.0 / 2 ได้ 2.5)
  • Modulus (%): Calculates the integer remainder of division (e.g. 7 % 3 == 1). Modulus requires integer operands only. การมอดุโลหรือหาเศษ (%): คำนวณเศษที่เหลือจากการหารจำนวนเต็ม (เช่น 7 % 3 == 1) ใช้ได้กับจำนวนเต็มเท่านั้น

2. Pre-increment vs Post-increment (++x vs x++) 2. การเพิ่มค่าก่อนและหลัง (Pre-increment vs Post-increment)

Unary increment (++) and decrement (--) operators behave differently depending on position in an expression: ตัวดำเนินการเพิ่มค่า (++) และลดค่า (--) มีพฤติกรรมการทำงานต่างกันตามตำแหน่งในนิพจน์:

  • Pre-increment (++x): Increments x first, then evaluates the new value in the expression. (e.g., if x=5, y = ++x assigns 6 to y). Pre-increment (++x): เพิ่มค่า x ขึ้น 1 ก่อน แล้วจึงนำค่าใหม่ไปใช้ในนิพจน์ (เช่น ถ้า x=5, y = ++x จะทำให้ y เป็น 6)
  • Post-increment (x++): Evaluates current x first in the expression, then increments x afterward. (e.g., if x=5, y = x++ assigns 5 to y, then x becomes 6). Post-increment (x++): นำค่า x เดิมไปใช้ในนิพจน์ ก่อน แล้วจึงเพิ่มค่า x ขึ้น 1 หลังเสร็จสิ้นคำสั่ง (เช่น ถ้า x=5, y = x++ จะทำให้ y เป็น 5 แล้ว x กลายเป็น 6)

3. Type Casting & Implicit Coercion 3. การแปลงชนิดข้อมูล (Type Casting & Promotion)

When operating between different types, C performs automatic promotion or requires explicit casting: เมื่อคำนวณระหว่างชนิดข้อมูลที่ต่างกัน ภาษา C จะปรับชนิดข้อมูลอัตโนมัติหรือต้องใช้การแปลงชนิดข้อมูลอย่างชัดเจน:

  • Implicit Promotion: Narrow types are automatically promoted to wider types (e.g., int + double promotes int to double). Implicit Promotion: ตัวแปรขนาดเล็กจะถูกปรับเป็นชนิดข้อมูลที่ใหญ่กว่าอัตโนมัติ (เช่น int + double จะปรับ int เป็น double ก่อนคำนวณ)
  • Explicit Casting: Prefixing an expression with (type) converts the result explicitly (e.g., (float)total / count avoids integer truncation). Explicit Casting: การระบุ (ชนิดข้อมูล) นำหน้านิพจน์เพื่อแปลงชนิดข้อมูลโดยตรง (เช่น (float)total / count ป้องกันการหารตัดเศษจำนวนเต็ม)

Pre-increment (++x) vs Post-increment (x++) Execution Order ลำดับการทำงาน Pre-increment (++x) เปรียบเทียบกับ Post-increment (x++)
