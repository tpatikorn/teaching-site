6.1 Pointers & Addresses

Learn standard variables references, memory address values, and dereference mechanics.

Address-Of (&) and Dereference (*)

A pointer is a variable that stores the memory address of another variable. By dereferencing (*p), we directly read or write the variable located at that address. Trigger pointer actions below.

1. Pointer Syntax & Size

• Declaration: Declared with an asterisk prefix (e.g. int *p; declares a pointer to an integer).
• Pointer Size: Pointers store addresses. On a 64-bit machine, all pointers occupy exactly 8 bytes, regardless of whether they point to a char or a double.

2. Pointer Arithmetic

Adding/subtracting from a pointer shifts the address relative to the size of the pointed type:
• If int *p stores address 1000, then p + 1 yields address 1004 (since sizeof(int) is 4).
• If double *d stores 1000, d + 1 yields 1008.

3. Void Pointers (Generic)

A void * is a generic pointer that can point to any type without a cast.
• However, it cannot be dereferenced directly or used in pointer arithmetic without first casting it to a concrete type (e.g. *(int *)vptr).
