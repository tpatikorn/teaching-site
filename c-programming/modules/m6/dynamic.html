6.2 Dynamic Memory Allocation (Heap)

Allocate structures dynamically using malloc and free, manage pointer links, and trace heap leaks.

Stack vs. Heap Memory

Heap memory is managed manually by the programmer. Functions like malloc() reserve blocks, returning raw address pointers. Memory must be explicitly released via free(), or it will leak in RAM until termination.

1. Allocators: malloc, calloc, realloc

• malloc(size): Reserves size bytes. Leaves bytes uninitialized (garbage values).
• calloc(num, size): Reserves num * size bytes and initializes every single byte to 0.
• realloc(ptr, new_size): Resizes a previously allocated block, copying contents to a new location if necessary.

2. Memory Leaks & Dangling Pointers

• Memory Leak: Occurs when heap memory is allocated but pointer reference is overwritten or goes out of scope without calling free().
• Dangling Pointer: A pointer that still stores the address of a block that has already been free()d. Dereferencing it is undefined behavior.
