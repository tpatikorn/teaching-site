6.4 A* Search

Shortest pathfinding using Manhattan Distance heuristics: f(n) = g(n) + h(n).

Concept Overview

A* Search is an extension of Dijkstra's algorithm that uses heuristics to guide its search. It computes the cost function:
f(n) = g(n) + h(n)
where g(n) is the distance from start, and h(n) is the estimated Manhattan distance to the destination.
