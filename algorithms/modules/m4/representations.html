Concept Overview

1. Adjacency Matrix: A 2D array of size $V \times V$. Cell [i][j] holds 1 (or edge weight) if there is an edge, else 0. Great for fast lookup (O(1)), but uses O(V²) space.
2. Adjacency List: An array of lists of size $V$. Each entry i lists all neighbors of vertex i. Space-efficient (O(V + E)).
