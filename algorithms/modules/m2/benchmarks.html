2.2 Data Structure Benchmarks

Compare performance of Arrays vs Linked Lists across large sizes of N.

Concept Overview

Theory states that inserting at the head of a Linked List is O(1), while in an Array it is O(N). Conversely, accessing elements by index in an Array is O(1), but in a Linked List it is O(N). Run the benchmark to prove this empirical scaling!
