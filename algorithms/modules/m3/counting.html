3.3 Counting Sort

A non-comparison sorting algorithm scaling in linear O(N + K) complexity.

Concept Overview

Counting Sort avoids comparisons. Instead, it counts the occurrences of each unique element in the input array. It uses these counts to compute the position of each element in the sorted output array. It operates in O(N + K) time, where $K$ is the range of key values.

Input Array
Counts (0-5)
Output Array
Step: 0 / 0
Status: Idle
# Python Counting Sort
def counting_sort(arr, max_val=5):
    count = [0] * (max_val + 1)
    output = [0] * len(arr)
    
    # 1. Count frequencies
    for num in arr:
        count[num] += 1
        
    # 2. Reconstruct sorted array
    idx = 0
    for i in range(len(count)):
        while count[i] > 0:
            output[idx] = i
            idx += 1
            count[i] -= 1
    return output

Analysis Metrics:

  • Time Complexity: O(N + K) best, average, and worst-case.
  • Space Complexity: O(N + K) to hold helper count and output arrays.
  • Constraint: Only works for integers within a known, relatively small range.
