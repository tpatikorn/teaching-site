Concept Overview

Quadratic sorting algorithms are simple to implement but inefficient for large datasets, scaling in O(N²) average time complexity. They use nested loops to compare and arrange elements.

# Bubble Sort Implementation
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
