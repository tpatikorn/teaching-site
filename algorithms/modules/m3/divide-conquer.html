Concept Overview

Divide & conquer algorithms break the array down into smaller subproblems, solve them, and combine the results. They scale in efficient O(N log N) time.

# Quick Sort Partition logic
def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i+1], arr[high] = arr[high], arr[i+1]
    return i + 1
