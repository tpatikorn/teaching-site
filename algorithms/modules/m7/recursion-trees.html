7.2 Recursion Trees

Visualize divide-and-conquer branching factors step-by-step using Fibonacci call tree.

Concept Overview

A Recursion Tree is a visual representation of recursive execution paths. Each node in the tree represents the cost/values computed by a single call. For functions with multiple recursive branches (like fib(n) = fib(n-1) + fib(n-2)), it demonstrates how the runtime expands exponentially.
