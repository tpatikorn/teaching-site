1.5 Hash Tables & Hashing

Interactive visual hash table comparing Chaining and Linear Probing step-by-step.

Concept Overview

A Hash Table maps keys to indexes using a Hash Function (e.g. h(x) = x % size). Ideally offering O(1) lookup, collisions occur when two keys map to the same index. We resolve collisions via Chaining (linked lists) or Open Addressing (linear probing).

Key Math

• **Load Factor (λ)** = Number of elements / Table size
• If λ exceeds 0.7 for open addressing, resizing (rehashing) is required.
