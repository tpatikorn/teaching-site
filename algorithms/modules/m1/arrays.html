1.1 Arrays

Master contiguous memory structures: indexing mathematics, element shifting mechanics, 2D row-major layouts, and CPU cache spatial locality.

1. Memory Contiguity & Indexing Formula

An Array stores elements in contiguous (consecutive) memory slots. Because addresses are sequential, accessing element A[i] takes instant O(1) time via the offset calculation formula:

  • Address(A[i]) = BaseAddress + (i * ElementSize)
  • Direct O(1) Access: Eliminates the need to traverse preceding elements.
  • Zero-Based Indexing: Index 0 aligns directly with BaseAddress offset zero.

2. Element Shifting & Insertion Costs

Inserting or deleting in the middle of an array requires shifting neighboring elements to prevent memory gaps or overlaps:

  • Insertion at Index i: Shifts elements from index i up to N-1 one slot right (O(N) operations).
  • Deletion at Index i: Shifts elements from i+1 down to N-1 one slot left (O(N) operations).
  • Append at End: Fast O(1) operation if pre-allocated capacity remains.

3. Multi-Dimensional Row-Major Order

Since physical computer RAM is linear (1D), 2D arrays A[rows][cols] map to 1D memory using Row-Major Order:

  • Address(A[i][j]) = BaseAddress + (i * Cols + j) * ElementSize
  • Rows are stored sequentially, one after another, in RAM.
  • Iterating through rows sequentially maximizes CPU cache hits.

4. CPU Cache Spatial Locality & Performance

Arrays deliver unmatched performance on modern hardware due to memory hierarchy optimization:

  • Spatial Locality: Accessing element A[i] automatically prefetches A[i+1]...A[i+k] into L1/L2 CPU cache lines (64 bytes).
  • Minimal Overhead: 100% memory utilization for data, with zero extra bytes wasted on node pointers.
