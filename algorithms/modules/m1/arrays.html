1.1 Arrays

Contiguous memory collection. Explore shifts, accesses, and search operations step-by-step.

Memory Contiguity

An Array stores elements in contiguous memory slots. Because memory addresses are consecutive, finding element A[i] takes O(1) time via simple formula:
Address = BaseAddress + i * ElementSize

Element Shifting

Inserting or deleting in the middle of an array requires shifting adjacent elements to prevent gaps or overlaps, making insertions and deletions average O(N).
