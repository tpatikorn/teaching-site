1.3 Stacks

Last-In, First-Out (LIFO) linear data structure.

What is a Stack?

A Stack is an abstract data type serving as a collection of elements with two principal operations:
• Push: Adds an element to the collection.
• Pop: Removes the most recently added element.
This behavior is known as LIFO (Last In, First Out).

Real-world & CS Applications

• Undo Mechanism in text editors (restoring states in reverse order). • Function Call Stacks (storing local variables and return addresses during recursion). • Expression Parsing (parenthesis matching and syntax tree conversions).
