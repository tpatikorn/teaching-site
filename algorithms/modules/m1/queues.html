1.4 Queues

First-In, First-Out (FIFO) linear data structure.

What is a Queue?

A Queue is a linear collection of elements supporting two main operations:
• Enqueue: Adds an element to the rear of the line.
• Dequeue: Removes an element from the front of the line.
This behavior is known as FIFO (First In, First Out).

Real-world & CS Applications

• OS Process Scheduling (CPU scheduler queues ready tasks). • Network Packet Queuing (buffer arrays in routers). • Breadth-First Search (BFS) (tracking node frontiers).
