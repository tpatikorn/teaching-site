1.2 Linked Lists

Master dynamic node structures: Singly, Doubly, and Circular Linked Lists, pointer rewiring algorithms, dummy sentinel nodes, and trade-off comparison against arrays.

1. Dynamic Heap Allocation & Node Structure

Unlike arrays, Linked Lists allocate nodes dynamically on the heap at scattered, non-contiguous memory locations:

  • Node Structure: Each node contains a data payload and a pointer address (next) referencing the subsequent node.
  • No Resizing Overhead: The list grows or shrinks dynamically without allocating contiguous blocks.
  • Head Pointer: A entry pointer storing the memory address of the first node (NULL if empty).

2. Singly, Doubly & Circular Variants

Linked lists are classified by their pointer connectivity and directional links:

  • Singly Linked List: Uni-directional links (next). Requires traversing from head to reach any node.
  • Doubly Linked List: Bi-directional links (next and prev). Enables $O(1)$ node deletion when given a target node pointer.
  • Circular Linked List: The tail node's next pointer wraps around to reference the head node instead of NULL (used in round-robin schedulers).

3. Pointer Rewiring & Sentinel Nodes

Modifying linked list structures requires updating memory address links in correct order to prevent dangling references:

  • Insertion Step 1: Point new node's next to target position's successor.
  • Insertion Step 2: Rewire predecessor's next to point to the new node.
  • Sentinel (Dummy Head) Pattern: Using an empty dummy head node simplifies code by eliminating edge-case checks for empty lists or head insertions.

4. Array vs Linked List Architectural Trade-offs

Selecting between arrays and linked lists depends on workload access patterns:

  • Random Access: Arrays $O(1)$ indexing vs Linked Lists $O(N)$ linear pointer chasing.
  • Middle Insertion: Arrays $O(N)$ element shifting vs Linked Lists $O(1)$ pointer rewiring (once node location is found).
  • Memory Overhead: Linked lists require extra 8 bytes per node on 64-bit systems for storing pointer addresses.
