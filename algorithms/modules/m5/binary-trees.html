5.1 Binary Tree & Traversals

Understand binary tree properties and animate In-Order, Pre-Order, and Post-Order traversals step-by-step.

Concept Overview

A Binary Tree is a hierarchical data structure where each node has at most two children (left and right). Traversals visit nodes in distinct patterns:
• Pre-Order (N-L-R): Root → Left → Right
• In-Order (L-N-R): Left → Root → Right
• Post-Order (L-R-N): Left → Right → Root
