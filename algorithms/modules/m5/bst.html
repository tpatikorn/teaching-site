5.2 Binary Search Trees (BST)

Learn node properties: left children hold smaller keys, right children hold larger keys.

Concept Overview

A Binary Search Tree (BST) maintains ordering among keys:
• Left subtree of node contains keys less than the node's key.
• Right subtree of node contains keys greater than the node's key.
Average search/insert time is O(log N), degenerating to O(N) if the tree is unbalanced (skewed).
